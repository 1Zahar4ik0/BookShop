# Bookshop

Одностраничный книжный магазин на Google Books API. Каталог загружается порциями по шесть книг, а корзина сохраняется в `localStorage`.

## Запуск

```bash
npm install
npm start
```

Сборка с минификацией:

```bash
npm run build
```

Проверка кода: `npm run lint`. Форматирование: `npm run format`.

Для публичных запросов ключ API не обязателен, но Google может ограничивать запросы без него. Чтобы использовать свой ключ, скопируйте `.env.example` в `.env` и заполните `GOOGLE_BOOKS_API_KEY`, затем пересоберите проект. Файл `.env` исключён из Git. Значение, переданное Webpack, попадёт в браузерный код, поэтому ограничьте ключ для Google Books API и своего домена в Google Cloud Console. Для хранения ключа в секрете понадобится серверный прокси.
